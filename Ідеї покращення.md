# Ідеї покращення та виправлені баги

## Виправлено

### 1. ForceBPM у Windows deployment (BUG)
**Проблема:** При виборі Windows розгортання + ForceBPM, модуль ForceBPM враховувався в розрахунку, хоча він призначений тільки для Kubernetes.

**Рішення:**
- Додано `IsKubernetesOnly` флаг до `ProjectModule`
- ForceBPM модулі позначено як `IsKubernetesOnly = true`
- `SizingEngine.CalculateWindows()` фільтрує K8s-тільки модулі
- `MainViewModel.OnDeploymentTypeChanged()` вимикає K8s-тільки модулі для Windows

### 2. Локалізація — неспівпадіння ключів
**Проблема:** JSON файли використовували ключі `tab.aiQueryTitle`/`aiQuery.*`, а код — `tab.assistantTitle`/`assistant.*`. Частина JSON ключів була не задіяна.

**Рішення:** JSON ключі приведено до єдиного стандарту — `tab.assistantTitle`, `assistant.*`.

### 3. Жорстко закодовані рядки
**Проблема:** `"~${0}/mo economy"`, `"Схему побудовано"`, `"Застосовано: {0}..."` не були локалізовані.

**Рішення:** Додано ключі `results.savings`, `status.diagramBuilt`, `status.applied` в обидві мови.

### 4. Файл BoolToColorConverter.cs (невідповідність назви)
**Проблема:** Файл називався `BoolToColorConverter.cs`, але містив клас `SeverityToColorConverter`.

**Рішення:** Файл перейменовано в `SeverityToColorConverter.cs`.

### 5. Створено .sln файл
- Додано `AIResourceCalculator.slnx` (.NET 10 формат)
- Додано `global.json` для фіксації версії SDK

### 6. Додано CI/CD (GitHub Actions)
- `.github/workflows/ci.yml`: build + test + publish
